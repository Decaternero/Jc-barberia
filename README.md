# JC Barbería

Sistema de gestión para la barbería JC.

La versión actual publicada en Render es una aplicación web estática. Los datos del prototipo se guardan en el navegador y **no se comparten entre dispositivos** hasta conectar una base de datos y autenticación en servidor.
